# 📌 QR Code Generator

This is a simple **QR Code Generator** project made using **HTML, CSS, and JavaScript**.  
It allows users to enter any **text or URL** and instantly generate a QR code, which appears with a smooth animation effect.

---

## 🚀 Features
- Generate QR Code from **text or URL**
- Modern **card-based UI design**
- Smooth **expand animation** for QR image
- **Error shake effect** if input field is empty
- Built with only **HTML, CSS, and JavaScript** (no external frameworks)

## 📂 Project Files

### 🔹 index.html
- Input field to enter **text or URL**
- Button to generate QR code
- Image box to display generated QR code
- JavaScript for functionality

### 🔹 styles.css
- Modern centered card layout
- Animated **shake effect** when input is empty
- Smooth **transition** when QR code appears
- Styled button & input field
